# clamp-adapter — 市販クランプ式トレイ用のデスク縁アダプタ

市販のクランプ式キーボードトレイ／引き出し（C字クランプ・対応厚み〜44.4mm程度）を、
**天板が厚い・天板下に幕板やフレームがあるデスク**に取り付けるためのアダプタです。

天板の上 → 縁の前 → 幕板の下端までを抱え込むC字フックで、前面に
**厚み20mmの「疑似天板（舌）」**を突き出します。市販クランプはこの舌を挟みます。
タイピングなどの前方荷重は、幕板下への回り込みが受けるので外れません。

```
      ┌── 天板上の腕(90) ──┐
 ═════╪════ 天板 ═══════════
 ▬▬▬▬▬│      ├幕板┤
 ↑舌   │      │    │
 (20mm)└──────┴────┘← 幕板の下に回り込む
```

**同じものを2個印刷**し、トレイの左右クランプの位置に取り付けます。

## ★ 印刷前に必ず実測して `generate.mjs` の params を合わせる

| パラメータ | 内容 | デフォルト |
|---|---|---|
| `deskT` | 天板の厚み（縁での実測） | 45 |
| `wrapDrop` | 天板の**上面**から幕板の**下端**までの距離 | 110 |
| `apronSetback` | 幕板の前面が天板の縁からどれだけ引っ込んでいるか | 0 |

購入したクランプが届いたら、あわせて確認:

| パラメータ | 内容 | デフォルト |
|---|---|---|
| `tongueDepth` | 舌の突き出し量。**クランプの喉の深さより大きく** | 70 |
| `ribSpan` | 舌上面のガイドリブ内寸。**クランプの顎の幅より広く** | 78 |
| `tongueT` | 舌の厚み（クランプ対応範囲の中央付近が無難） | 20 |

```bash
cd models/clamp-adapter
npm install
node generate.mjs   # stl/ を再生成（寸法・水密性・ビルド範囲を検証して表示）
```

`stl/print/adapter.stl` が印刷向き（側面を下にした横倒し・サポート不要）、
`stl/assembly/` は組立位置＋デスク断面の参考モデル（`_reference_desk.stl` は印刷不要）です。

## 取り付け

1. デスクの端（横）からスライドさせて縁に通す
   - 横から入れられない場合は `underlap: 0` にすると前から差し込めるが、
     保持力が落ちるので非推奨（せめて 10 は残す）
2. 左右2個をクランプの間隔に合わせて配置
3. 市販クランプで舌を挟んで固定。クランプのネジは強く締めてよい
   （舌は積層方向が圧縮・曲げに強い向きで印刷される）

## 印刷設定の推奨

- PLA または PETG、**壁4ライン以上・インフィル25%〜**
  （クランプの締め付けと荷重を受けるため、強度優先）
- 横倒し配置のままサポート不要
- 舌の上面がクランプで滑る場合は、舌に滑り止めシートを貼るか `tongueT` を調整

## 耐荷重の目安

キーボード＋マウス程度（〜2kg）を想定。乗って体重をかけるような使い方は不可。
