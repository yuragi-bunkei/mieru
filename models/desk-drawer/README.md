# desk-drawer — 天板に引っ掛ける後付け引き出し

PCデスクの天板の縁にC字フックで掛けて使う、後付けの引き出しです。
スマホスタンドと同じ「工具不要・天板の縁に掛けるだけ」の固定方式で、
全パーツが Bambu Lab A1 mini（180×180×180mm）に収まります。

```
        ┌──天板の上に載る腕──┐
  ══════╪════ 天板 ═══════════╪══════
   前面 │                      │
   ﾌﾟﾚｰﾄ└─レール(45°Vミゾ)────┘←タイバー
        ┌──────────────────┐
        │   引き出し（スライド） │
        └──────────────────┘
```

## パーツ

| ファイル | 個数 | 役割 |
|---|---|---|
| `bracket_right.stl` / `bracket_left.stl` | 各1 | フック付きレール（左右対称） |
| `drawer.stl` | 1 | 引き出し本体（内寸 約145×149×42mm） |
| `tie_bar.stl` | 1 | 左右レールの間隔を固定する後方の梁 |

`stl/print/` が印刷向き（全パーツサポート不要）、`stl/assembly/` が組立位置です。
mieru でどちらのディレクトリも確認できます。

## ★ 印刷前に必ず

`generate.mjs` 冒頭の **`deskThickness`（天板の厚み）を実測して合わせて**
再生成してください（デフォルト25mm）。フック開口は実測値+0.5mmになります。

```bash
cd models/desk-drawer
npm install
node generate.mjs   # stl/ を再生成し、寸法・水密性・ビルド範囲を検証して表示
node check-slide.mjs # 引き出しのスライド干渉チェック（戻り止め以外の交差=0が正常）
```

## 設置条件

- 天板の縁に **奥行き45mm** ぶん物が置ける平らな面があること（腕が載る）
- 天板の下に **奥行き170mm・高さ50mm** の空間があること（幕板・引き出しレール等と干渉しないこと）

## 組み立て

1. ブラケット2個を天板の縁に掛ける（間隔はだいたいで良い）
2. タイバーを両ブラケット後方の切り欠きに上から落とし込む → 間隔が固定される
3. 引き出しを前からレールに滑り込ませる。奥のバンプを「カチッ」と乗り越えたら装着完了
4. 外すときは強めに手前へ引き抜く

## 設計メモ

- **摺動部は45°のV字**: 引き出し側リブの下面とレール受け面がともに45°斜面。
  自重でセンタリングされ、両パーツともサポートなしで印刷できる向きになる
- **戻り止め**: レール前方の丸バンプ（φ3）にリブが約0.3mm干渉。通常operationでは
  抜けず、強く引くと乗り越えて外せる
- **浮き上がり防止**: レールに上フランジがあり、引き出しを引き出したときの前傾を抑える
- **印刷向き**: ブラケットは外側面を下に横倒し（`stl/print/` で配置済み）。
  引き出しは底面を下に。ハンドルとリブの下面は45°ガセットでサポート不要
- 推奨: PLA、壁3ライン以上、インフィル15%〜。重い物（〜500g程度）を入れるなら壁4ライン

## パラメータ

主要な値は `generate.mjs` の `params` にまとまっています:
`deskThickness`（天板厚・要実測）, `drawerW/drawerDepth/drawerHeight`（引き出しサイズ）,
`railLen`, `hookDepth`, `slideGap`（渋い/ゆるい場合の調整）など。
