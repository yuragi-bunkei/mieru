# clamp-spacer — 幕板裏に貼るかさ上げスペーサー

市販クランプ式トレイ（サンコー「スライド式キーボードトレイ2」等）を
幕板付きのデスクに取り付けるとき、クランプの下顎が幕板の下端に
面で当たるように**幕板の裏に貼ってかさ上げする**ブロックです。
木材（横200×奥行き40×高さ53mm）の代替として印刷します。

全長200mmはA1 miniのビルド範囲（180mm）を超えるため、
**100mm×2個（A=オス、B=メス）をアリ継ぎで連結**して200mmにします。

| ファイル | 形 | 印刷数 |
|---|---|---|
| `stl/spacer_a.stl` | 本体＋アリホゾ（オス） | クランプ1箇所につき1個 |
| `stl/spacer_b.stl` | 本体＋アリ溝（メス） | クランプ1箇所につき1個 |

クランプ2箇所に付けるなら **A×2 + B×2 の計4個**。

## ★ 印刷前に

`generate.mjs` の `height`（デフォルト53）が
**「天板の下面〜幕板の下端」の実測値**と合っているか確認してください。
ここが合わないとクランプ下顎が浮くか、幕板下端より出っ張ります。

```bash
cd models/clamp-spacer
npm install
node generate.mjs   # 寸法・水密性・連結時の全長と干渉ゼロを検証して出力
```

## 印刷設定（強度優先・重要）

クランプの締め付け力を受け続ける部品です:

- **PETG推奨**（PLAでも可）
- **壁6ライン・インフィル40%以上**（グリッドかジャイロイド）
- 向き: そのまま（100×40面を下）。サポート不要
- はめあいがきつい場合は `fit` を 0.3 に、ゆるい場合は 0.1 にして再生成

## 取り付け

1. AとBを上からスライドさせてアリ継ぎで連結（200×40×53のブロックになる）
2. **下面を幕板の下端と面一**に揃えて、強力両面テープで幕板の裏へ貼る
3. クランプで「天板＋幕板＋スペーサー」をまとめて挟んでネジ締め
4. **設置1〜2週間後にネジを増し締め**する（樹脂の初期なじみ対策。以後は不要）

## 注意

- クランプに挟まれる総厚は「天板の厚み + height」。製品の対応範囲
  （スライド式キーボードトレイ2は5〜85mm）に収まることを事前に確認
- 発泡スチロール・コルク等での代用は不可（締め付けで潰れて緩みます）
