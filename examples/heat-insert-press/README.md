# heat-insert-press — ヒートインサート圧入治具

はんだごてを垂直に保持し、3Dプリント品にインサートナット（真鍮ヒートインサート）を
まっすぐ圧入するための治具です。スクリプト（JSCAD）からSTLを出力するタイプの
モデリング例で、mieruで表示確認しながらパラメータを調整できます。

![組立プレビュー](docs/preview-assembly.png)

## 設計方針: 摺動ではなく転がり

樹脂同士の摺動ガイドはスティックスリップ（静止摩擦＞動摩擦で起きるカクつき）が
避けられず、圧入の瞬間に「引っかかり→ガクッと落下」するとインサートが斜めに
入る原因になります。そのため本設計では:

- 案内は**608ZZベアリング6個の転がり**とし、摺動摩擦に頼らない
- 戻り抵抗は摩擦ではなく**輪ゴムの弾性**で作る（柱上部の周回溝と
  キャリッジ側ペグに掛ける）。滑らかで予測可能な抵抗になる
- 印刷公差によるガタは、背面軸の**偏心ブッシュ**（六角フランジを回すと
  ベアリング位置が±0.75mm動く）で組立後に調整する

## 必要な市販部品

- 608ZZベアリング ×6（1個100円前後の汎用品）
- 温度調整式はんだごて（設計基準: YIHUA 928D-III。グリップ最太部⌀22mm実測）
- M3×20 なべ小ねじ ×2 + M3ヒートインサート（外径5.0×長さ4.0） ×2 … クランプ締め付け用。
  片側の耳の外面からインサートを熱圧入する（下穴⌀4.6×深さ6.0）
- 輪ゴム … 戻り抵抗・上保持用
- （任意）M8×70ボルト+ナット ×4 … 印刷軸の代わりに使うと剛性が上がる
- （任意）木ネジ ×4 … ベースを作業台に固定する場合（⌀4.5穴）

## 使い方

```bash
cd examples/heat-insert-press
npm install
npm run build        # 印刷用STL一式を stl/ に出力
npm run assembly     # stl/assembly.stl（組立プレビュー、印刷不可）を出力
```

mieruで確認する場合（リポジトリルートで）:

```bash
node server.js examples/heat-insert-press/stl
```

## 組立

1. 前面2軸: 軸を側壁に通しながらベアリングを2個ずつ通し、キャップで留める
2. 背面2軸: 側壁の⌀12穴に偏心ブッシュを外側から差し込み、軸を通しながら
   ベアリングを1個ずつ通し、キャップで留める
3. キャリッジを柱の上端からかぶせて下ろす
4. 偏心ブッシュを回して、ガタがなく・軽く転がる位置に調整する
   （固い場合はブッシュを少し戻す。調整後は瞬間接着剤を一滴垂らすと保持が安定）
5. キャリッジ右耳（+X側）の外面にM3インサート2個を熱圧入する
   （このインサート自体は手持ちのこてで普通に入れてよい。治具完成前の最後の手作業）
6. はんだごてを上からリングに通し、M3×20ねじ2本で軽く締めて固定。
   リング（高さ40mm）はグリップの直胴区間（47.5mm）に収まる。操作ボタンや
   LED表示を覆わない位置で締めること（こて先がキャリッジ下端から3〜5cm出る位置が目安）
7. 輪ゴムを柱上部の周回溝に巻き、キャリッジ右側面のペグに掛ける

## 圧入のしかた

1. ワークをベース上のこて先直下に置き、インサートを穴に仮置き
2. こてを設定温度（真鍮インサート: PLA/PETGなら200〜250°C目安）にする
3. キャリッジをゆっくり押し下げ、インサートの上面がワーク面と揃ったら
   すぐ引き上げる（押し込みすぎ防止）

## パラメータ調整

`model.js` 冒頭の `P` を編集して `npm run build` で再生成します。主なもの:

- `ironDiameter` … こての保持部外径（928D-III実測22.0mm）。ボアは
  `clampClear`（片側0.3mm）を足した⌀22.6で、割りを締めて詰める
- `ringH` … クランプリング高さ（初期値40mm）。グリップ直胴区間より短くすること
- `axleHole` / `bushHole` … 軸・ブッシュの穴径。プリンタの穴縮み具合に応じて調整
- `padGap` … 横ガイドパッドのクリアランス（初期値0.25mm）
- `towerH` / `baseW` / `baseD` … 柱の高さとベース寸法

## 印刷の目安

- 向き: すべてSTLの向きのまま（自立する向き）で印刷。⌀8軸は垂直印刷なので
  ブリム推奨。強度が不安ならM8ボルトに置き換える
- 材料: PETG推奨（こての熱が伝わる可能性があるためPLAより耐熱性のあるもの）
- インフィル20〜30%、キャリッジは壁3周以上を推奨

## 注意

- こて先やヒーター部が直接触れる部分に樹脂部品が来ない構成ですが、
  長時間の連続使用ではクランプ部の温度に注意してください
