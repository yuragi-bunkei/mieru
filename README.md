# mieru — STLライブビューア

Claude Codeで3Dプリント用のモデリング（スクリプトからSTLを出力するタイプ）をするときに、
出力STLを常時表示し、ファイルが更新された瞬間に自動リロードするローカルビューアです。

Claude Codeデスクトップアプリの**Browserペイン**に並べて表示することで、
コードの修正と形状の変化を同時に確認できます。Claude自身もスクリーンショットで
形状を確認できるため、「作る → 見る → 直す」のループが短くなります。

- 完全ローカル（外部通信なし）
- ビルド工程なし（バンドラ不使用。three.js は importmap で読み込み）

## インストール

```bash
git clone <このリポジトリ> ~/dev/mieru && cd ~/dev/mieru && npm install
```

## 起動

```bash
node server.js <監視ディレクトリ> [--port 5301] [--last]
```

ブラウザで http://localhost:5301 を開きます。

- 監視ディレクトリを省略するとカレントディレクトリを監視します
- `--last` を付けると、前回 `/watch` で切り替えた監視先を復元します
- 起動後に監視先を変えるには `curl "http://localhost:5301/watch?dir=<絶対パス>"`
  （引数なしで `/watch` を叩くと現在の監視先を返します）

## 機能

**ライブリロード** — 監視ディレクトリ以下の `*.stl` を再帰的に監視し、追加・更新・削除を
即座に画面へ反映します。更新時も視点は保持されるので、見ていたアングルのまま形だけが変わります。

**マルチビュー** — 1 / 2 / 4画面に分割でき、各ビューは独立したカメラで自由に回せます。
複数アングルが1枚のスクリーンショットに収まるため、AIエージェントに複数方向の状態を
まとめて渡せます。

**十字回転ボタン** — 各ビューの右下に十字パッドがあり、押している間だけそのビューの
視点が回転します。マウスドラッグより狙った角度に合わせやすく、極（真上・真下）の
手前で止まるため視点の反転が起きません。

**描き込み** — 画面の上にペン・矢印・文字（赤）で直接指示を描けます。描いた内容は
スクリーンショットに写るので、そのまま修正指示として読み取らせられます。描き込み中は
対象のビューが赤枠で示されます。

**寸法と目安** — 表示中メッシュ全体のバウンディングボックス寸法（mm）を常時表示。
180×180mmのビルドプレートグリッドと原点を貫く座標軸を重ねられます。

**そのほか** — ファイル別の表示切替（複数表示時は色分け、単体表示は白）、ワイヤーフレーム、
断面スライダー（X/Y/Z軸）、全体表示・視点リセット、自動回転。

**状態の自動復元** — ビュー分割数・各ビューのカメラ視点・ファイル別表示・ワイヤーフレーム等の
表示設定・断面・描き込み（指摘リストのメモ／チェック含む）を、操作のたびにサーバーへ自動保存
します。ページを開き直すだけで前回見ていた状態に戻るので、セッションが中断してもそのまま
再開できます。サーバー再起動もまたぎます。保存先は `.ui-state/` に監視ディレクトリごとの
別ファイル（アトミック書き込み）なので、複数プロジェクトでインスタンスを並行起動しても
互いの状態を消しません。

## 設計上の注意

- **オンデマンド描画**: 連続的な requestAnimationFrame ループは使わず、カメラ操作・ファイル
  更新・UI操作のときだけ描画します。Browserペインはバックグラウンドで rAF が止まるため、
  常時ループだと描画が凍って見えるのを避ける狙いです。スクリーンショット検証時に描画が
  止まって見える場合は `window.dispatchEvent(new Event('resize'))` で再描画を強制できます。
- **ローカル専用**: 認証機構はありません。外部に公開しないでください。

## 開発

```bash
npm test
```

`node:test` によるサーバー側のテスト（静的配信、パストラバーサル遮断、ヌルバイト耐性、
ファイル監視とWebSocket配信、異常切断への耐性、監視先切替の永続化）が動きます。
ビューアの見た目はブラウザでの目視確認です。

設計書と実装計画は `docs/superpowers/` にあります。
